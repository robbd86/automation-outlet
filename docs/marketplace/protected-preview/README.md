# Protected account preview
Build uses the official pinned Supabase JS 2.119.2 UMD package, npm tarball integrity, no dependency installation or runtime CDN. Preview only: VERCEL_ENV must equal preview and VERCEL_URL must identify the isolated project. Supply preview-settings.json containing development URL and publishable key at deployment time. Never use a service-role key. Registration/recovery require the exact deployed account.html URL in Supabase URL configuration. Internal test accounts only; configure CAPTCHA, SMTP and hosting eligibility before customer use. Run node --test auth-client.test.mjs during build. No production or live AO credentials.
