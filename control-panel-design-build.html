From specification to handover

The exact design and testing documentation depends on the application, assembly classification and agreed project scope.

Requirements and electrical design

Machine function, available supply, load schedules, protection, enclosure, safety interfaces and documentation requirements reviewed up front.

Assembly and functional testing

Panel construction, identification, continuity and relevant electrical checks, with functional testing and FAT arrangements agreed in advance.

Drawings, installation and commissioning

Schematics, wiring changes, software integration and the handover package defined in the quotation, with installation or commissioning by agreement.

Standards and conformity requirements are assessed for each project. No blanket certification or compliance claim is made without a verified design, applicable testing and documentation. For software integration, see PLC programming and HMI development.

Common questions

Can you build to existing electrical drawings?

Yes, a build-to-drawing enquiry can be reviewed. Supply drawings, panel dimensions, component list, required test evidence and delivery details.

Can you refurbish or rewire an existing panel?

Potentially. We first review the machine, the condition of the existing assembly, safety implications and whether replacement is a better option.

What information is needed for a quote?

A brief sequence of operation, supply details, motors/loads, I/O list, any existing schematic, enclosure constraints and proposed PLC/HMI platform.

Need engineering support?

Send the machine type, PLC or HMI model, project scope and any drawings or fault information. We'll review the requirements before agreeing work.
