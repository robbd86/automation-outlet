How to use these guides: Identify the exact CPU/drive type and installation first. Diagnostic LEDs are clues, not proof that a CPU has failed. Do not bypass guarding, defeat safety systems, change a live programme or reset a machine to clear a fault without your site's authorised safe process.

Record these details before replacing a PLC

  1. Photograph all current LED states and note the time and machine symptom.
  2. Read and save the first relevant diagnostic events before a power cycle.
  3. Record the complete manufacturer order number, firmware, communications and I/O layout.
  4. Verify you have a usable programme and parameter backup, with approved restoration and restart procedures.
  5. If a component appears faulty, distinguish a confirmed failure from wiring, supply or network causes.
