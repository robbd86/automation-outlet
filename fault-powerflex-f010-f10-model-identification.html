PowerFlex F010 / F10: which drive?

This search does not have one universal answer. Rockwell's PowerFlex 40 and 525 fault lists omit F10/F010, but PowerFlex Digital DC drives use F10 for a main-contactor fault. Identify the exact drive before acting.

Checked against Rockwell published documentation · 27 October 2026

F010 means different things depending on the series

Check the catalog/series label — not just the word “PowerFlex” on the keypad. A code can be absent from one family's published fault table and used by another family.

22B · PowerFlex 40

F10 is not in the published fault table

Rockwell lists F8 (heatsink overtemperature) followed by F12 (hardware overcurrent). Recheck whether the display is showing a fault, parameter, or code from a different device.

See PowerFlex 40 fault table (page 93) ↗
25B · PowerFlex 525

F010 is not in the published fault table

The fault list progresses from F009 (control module overtemperature) to F012 (hardware overcurrent). Confirm the displayed characters and full drive model.

See PowerFlex 525 fault table (page 5) ↗
20P · PowerFlex Digital DC

F10: Main Contactor

Rockwell's Digital DC service documentation uses F10 for a fault concerning a main contactor used with the drive. It is not equivalent to the 40/525 drive faults.

See Rockwell Digital DC service manual ↗

How to investigate safely

  1. Record the precise catalog number (for example, 22B, 25B or 20P), firmware where available, and exact keypad text. Take a clear photo before clearing a fault.
  2. Confirm whether the indication is an actual fault, a display/parameter code or a message from an upstream PLC/HMI.
  3. For a PowerFlex 40 or 525, compare the code with the matching fault table above. Do not assume F010 is hardware failure.
  4. For a PowerFlex Digital DC with F10, review the manufacturer's contactor control and feedback arrangement against the electrical drawings. Qualified personnel should check contactor status, relevant interlocks and the fault history under approved safe procedures.
  5. Correct the underlying cause and assess restart consequences before a reset. Preserve logs and any drive configuration backup.
Do not bypass contactors or safety circuits to clear a code

Drive and mains/DC circuits can retain hazardous energy after isolation. Use the manufacturer's instructions, safe isolation and a competent electrical engineer. A code alone does not justify replacing or resetting a drive.

Commonly confused nearby faults

For PowerFlex 525, F009 is control-module overtemperature and F012 is hardware overcurrent. Those are separate faults; do not infer that F010 means either of them.
