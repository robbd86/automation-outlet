Common questions

Can you modify an existing HMI rather than replace it?

Often yes, provided the software project, access and hardware compatibility can be established. A backup and change-control approach should be agreed first.

Do you provide remote HMI programming?

Some screen changes and project reviews can be done remotely. Downloading and commissioning on a live machine needs an agreed safe on-site or supervised process.

What should I send to get a quote?

HMI model, PLC type, software version if known, photographs, existing project availability and a list of requested changes.

Need engineering support?

Send the machine type, PLC or HMI model, project scope and any drawings or fault information. We'll review the requirements before agreeing work.
