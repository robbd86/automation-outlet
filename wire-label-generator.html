How to make wire labels from an Excel I/O list

For control-panel builders, PLC engineers and maintenance teams who need a practical printed schedule rather than another spreadsheet to format.

  1. Export an I/O list as .xlsx or .csv, or paste cells directly from Excel. The Excel importer reads the first worksheet.
  2. Map columns for PLC address or tag, description, optional terminal and optional wire number.
  3. Correct identifiers in the editable table. Select Wire marker, Terminal or PLC I/O in the label settings.
  4. Preview the labels, set their dimensions, then print on A4 or choose Save as PDF. Check printer scaling is 100% / actual size.

Frequently asked questions

Can I generate labels from Excel?

Yes. Use a .xlsx file, CSV, or copy and paste a table of cells. Older .xls workbooks are not supported by this first version.

Does the spreadsheet leave my computer?

No. Import, mapping and label generation run within your browser. You do not need an AO account to use this tool.

Will these labels fit any proprietary label printer?

Not necessarily. This tool generates generic A4 layouts and downloadable CSV data, not native Brother, Brady, Phoenix Contact or other printer-specific file formats. Test the dimensions on your own media first.

Can I use the labels as approved wiring documentation?

No. This is a formatting utility. Confirm every address, wire and terminal against the approved machine schematics and your own panel documentation before use.
