What the Snapshot shows

Engineering metrics, not AI theatre

Code structure & activity

Controller and project identity, blocks, networks, calls, writes, multiple writers and investigation counts. The result model also records what the engine could and could not analyse.

Evidence confidence

Findings carry VERIFIED INFERRED or UNKNOWN evidence status so assumptions are separated from facts extracted from the project.

Confidential engineering files

Private upload architecture

PLC source projects are treated as confidential engineering files. The browser uploads directly to private object storage using a short-lived permission scoped to one opaque pathname. The Automation Outlet application does not proxy the PLC project through a normal serverless request body and does not expose a permanent private object URL.

Uploaded projects are retained only for the configured analysis/retention period and can be deleted from the customer audit view. A local Windows analysis option is planned for organisations that cannot upload PLC source code.

Engineering limitation

Code evidence is not live-machine proof

PLC Intelligence analyses the supplied project. It cannot prove current I/O state, field wiring, mechanical condition, online values, safety validation, machine timing or whether the uploaded project exactly matches the controller currently running on site.

Use the result as engineering evidence and triage. Verify critical conclusions against the live machine, drawings, backups and commissioning records.
